# Project instructions

- Use public data only.
- Prefer simple, reproducible Python and Jupyter implementations.
- Verify originality against prior research; retain a source and claim ledger.
- Separate predictive associations from causal claims.
- Prioritize findings that could inform team decisions.
- This project is independent of SIMPSON and xSIMPSON.
- Follow thorough research processes suitable for SABR submission.
- Validate timestamp semantics, precision, and interruptions before calling intervals release tempo.
- Define every opportunity and freeze predictors before the response.
- Include nonattempts and opportunities that end without another pitch.
- Use chronological validation; never tune on the final test period.
- Report missingness, exclusions, uncertainty, and negative findings.
- Do not commit secrets, raw downloads, or unreviewed notebook outputs.
- Update docs/decision_log.md when research definitions or analysis choices change.
