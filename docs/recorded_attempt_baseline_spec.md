# Initial recorded-attempt baseline: frozen specification v1

Frozen 2026-11-15 before model fitting or new 2024 outcome inspection. Existing historical QA summaries were read. Source checkpoint: 4af9c1d. This addendum overrides only the split/model choices below.

- Population: every frozen v1.1 first-base-only window in the complete 2022–2024 tables. Opens before the first PA event or after its opening anchor; closes at next actual pitch, state exit, or terminal boundary. Retain terminal and runner-change windows, including nonattempts. Predict any recorded attempt in the window, not necessarily by its opening runner. Do not filter using future identity changes or history-count eligibility. Existing history-count exclusions remain unchanged.
- Label: recorded_steal_attempt_indicator (at least one parser-classified steal_attempt record; stolen_base/caught_stealing event or movement evidence). Pickoff-only events are not attempts. Ambiguous success outcomes still count as attempts. This is a public-feed label, not a census of real attempted steals.
- Cutoff: before first event or immediately after opening anchor. Only inning, half_inning, open_balls, open_strikes, open_outs, open_timing, and opening disengagement state enter context. No closing results, response actions, identity-change flags, terminal flag, timestamps, or current-game histories enter X. Identities, score and previous pitch are omitted in this first baseline.
- Rule state: post-2023 flag, recorded_disengagements_at_open, and post-2023 resets/remaining allowances. Pre-2023 reset/remaining values are structural zero plus rule indicator, not an assumed two-throw rule. Reuse audited advance resets and continuation handling.
- History models: context plus post_2023 history alone; context plus separate pre_2023 and post_2023 blocks. Each block uses log1p eligible opportunities, smoothed attempted-opportunity rate (A + 100*p)/(N + 100), and zero-exposure indicator. p is the fit-partition prevalence; 100 is fixed, not tuned. No success predictors for this milestone. Counts are the existing completion-before-start snapshots, never career totals. Zero exposure receives p. Missing/incomplete histories stop the run; numeric context uses fit-only medians and missing indicators; categorical missing = MISSING, unseen = ignored.
- Split deviation requested by Isaac: fit on 2022–2023 (2022 previously history-only); 2024 is a fixed held-out development evaluation, not a pristine final test. 2025 stays unopened. Within training, fit a diagnostic model using games completed before 2023-07-01 UTC, score games starting on/after that date; crossing games excluded from this diagnostic only. Full refit uses games completed before 2024-01-01 UTC. Historical counts in later games may update from earlier completed games; fitted parameters do not.
- Candidates fixed in advance: pooled training prevalence; context-only logistic; post-history logistic; separate-block logistic. L2 logistic C=1, lbfgs, max_iter=2000, no class weights, standardized numeric features and one-hot categoricals. Report all, do not choose a winner using 2024. No parameter search. Separate-block logistic is the declared primary candidate.
- Calibration policy: identity/no recalibration, fixed before evaluation. Report chronological training diagnostic and final 2024 performance. Calibration intercept/slope fitted to evaluation predictions are descriptive diagnostics only, never applied. No in-sample predictions are suitable for subsequent pitcher-response work.
- Metrics: log loss, Brier, average precision, prevalence, counts; fixed probability bins [0,.005,.01,.02,.05,.1,.2,1] with counts and attempts. Subgroups: opening disengagement count, history depth, terminal and runner-change audits; no unstable individual rankings or coefficient interpretation. 200 whole-game bootstrap resamples with seed 20261115 yield percentile 95% intervals and paired deltas vs constant. Fixed predictions, no refitting: uncertainty is conditional on training and does not include model selection uncertainty.
- Verify existing tests and historical invariants, save input/spec SHA256, environment, model preprocessing/calibration artifact, predictions locally, compact results and report. No causal, tempo, success, or expected-run conclusions. Originality remains provisional under the existing source/claim ledger; this baseline makes no novelty claim.
