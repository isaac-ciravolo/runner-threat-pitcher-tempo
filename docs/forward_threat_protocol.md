## Pre-score execution amendment: chronology quarantine
The first run stopped before policy selection or 2024 scoring because 2023 game 716404 has feed start 2023-10-02 after completion 2023-09-29. A timestamp-only scan found exactly 61 affected rows and no other completion-before-start cases in 2022–2024. Retain these rows as quarantined/unscored; exclude them from base fits and calibration, rather than invent a start or use their potentially future-informed own-game histories. Final 2024 scoring now refits the same frozen primary model on the remaining 276,533 training rows instead of reusing the baseline artifact containing those 61 rows. Earlier-game history counts in other rows are unchanged: the completion-time rule still determines their availability. Resolving actual-start semantics and reconstructing the quarantined game's histories remains required before restoring its rows. This is a validation-driven denominator deviation, not an outcome-driven selection. The original baseline is preserved but its chronology gate was incomplete.
